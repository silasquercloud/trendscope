# TrendScope

Creator Studio para YouTube e TikTok, preservando a base visual [Studio Admin](https://github.com/arhamkhnz/next-shadcn-admin-dashboard).

**O aplicativo está em `trendscope/`.** Configure esse diretório como Root Directory no Render e na Vercel. `render.yaml` fica na raiz do repositório.

```bash
cd trendscope
npm ci
npm run build
npm run start
```

O painel abre sem credenciais, em estado vazio e tema escuro por padrão. O modo demonstrativo foi removido; não contém métricas ou receitas inventadas. Nenhuma integração externa é anunciada como validada sem um teste real com credenciais.
